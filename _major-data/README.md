# 최근 5개년 주요 뉴스

원본은 `major.json`, 배포 데이터는 `assets/js/data-major.js`입니다.
저장소 루트에서 `pwsh -File _tools/build-major.ps1`로 검사하고 생성합니다.
관리 화면 `_tools/news-admin.html`도 같은 원본과 분류를 사용합니다.

## 기간·분류

- 원문 발행일 기준 오늘로부터 5년 이내를 기본 표시합니다. 5년 경과 기사는 삭제하지 않고 보관 필터로 제공합니다.
- `한국-동유럽`(`korea`)은 한국 정부·기업·기관이 직접 당사자인 외교·산업·협력 사건입니다. 단순히 한국에 시사점이 있다는 이유만으로 넣지 않습니다.
- 각 사건은 하나의 주 분류에만 등록합니다. 한국 관련 뉴스의 기존 산업 세부 분야는 키워드로 보존합니다.
- 원문 날짜와 사건 날짜가 다르면 요약에 실제 사건 날짜를 씁니다. 발표 계획, 계약 체결, 가동 완료, 금융 한도와 실제 집행액을 구분합니다.
- `review: ai`는 사람이 최종 검토한 것으로 표시하지 않는 기존 운영 규칙을 유지합니다.

## 중복을 판단하는 기준

1. 새 제목을 쓰기 전에 기존 제목뿐 아니라 요약·핵심 내용·출처를 대조합니다.
2. 당사자, 대상 사업·법안·선거·사고, 결정 또는 행위가 같으면 같은 사건으로 봅니다.
3. 다른 매체의 재보도·번역 기사·단순 후속 보도는 기존 항목의 출처와 내용에 통합합니다.
4. 서로 다른 국가의 법률·선거, 다른 사업자·설비·계약, 다른 시기의 독립된 재난은 같은 주제라도 별도 사건입니다.
5. 같은 사건을 여러 국가·분류에 복제하지 않고 국가 태그를 함께 부여합니다.
6. URL·제목 중복 자동 검사는 보조 수단이며, 의미가 같은 사건의 중복은 위 기준으로 편집 검토합니다.

## 2026-11-12 확장 기록

- 기존 23건 유지, 신규 30건 추가: 총 53건. 20개국 모두 관련 기사가 있습니다.
- 한국 관련 기존 4건(두코바니·K2·천무·루마니아 K9)을 이동하고, 신규 5건을 추가해 한국-동유럽은 9건입니다.
- 크로아티아 유로·솅겐 가입은 하나로 통합했습니다.
- 코소보 무비자의 결정·시행, 흑해 곡물 협정의 출범·종료, 한국의 우크라이나 EDCF 공여협정·기본약정은 각각 하나의 항목으로 묶었습니다.
- 기존 두코바니 우선협상·본계약, K2·천무 기본계약·실행계약, 발트 전력망 분리·동기화는 별도 신규 기사로 추가하지 않았습니다.
- 리투아니아 가스 수입 중단과 발트 전력망 동기화는 에너지원·운영 체계가 다른 사건입니다.
- 몰도바 헌법 국민투표와 EU 가입 협상은 국내 헌법 결정과 국제 협상이라는 별도 사건입니다.
- 슬로베니아 2023년 홍수와 2024년 폭풍 보리스는 별개의 재난입니다.
- 신규 원문은 AP, Axios, PAP, ERR, Moldova 1, OSW, RFE/RL, 한국 외교부, EU·유엔·OSCE, 현지 의회·정부 및 기업 공식 발표 등으로 다양화했습니다.
- 모든 신규 항목의 출처 URL은 해당 항목에 보존합니다. 시사점은 사실 인용과 구분되는 편집 해석입니다.
