언어 개요

인도유럽어족 → 슬라브어파 → 남슬라브어군. 키릴 문자를 사용하는 언어. 세르비아어와 같은 문자만을 공유하는 것이 아니라 남슬라브권 공통 특성도 존재.

문자 및 표준 알파벳: 현대 불가리아 표준 알파벳은 30자. ѝ는 별도의 글자가 아니라 и에 강세를 표시한 표기이며 옛 문자 ѣ 등은 현대 30자에 포함되지 않음.

강세 및 실제 발음: 강세 위치는 단어에 따라 달라짐. 강세를 받지 않는 모음은 실제 발음이 약화될 수 있고, 단어 끝 유성 자음은 무성화될 수 있음.

알파벳 전체 + IPA

IPA는 대표 음소 또는 가장 흔한 음가를 기록한다. 여러 음가가 있는 경우 함께 표시한다. 교실에서 보이는 표가 아니라 실제 음운규칙까지 설명하는 학습용 자료이며 한국어 표기와 IPA를 동일시해서는 안 된다.

IPA와 철자 발음 규칙

  • Ъ ъ는 한국어 ㅡ와 완전히 동일하지 않은 후설 비원순 계열 /ɤ/가 대표값.
  • Ь ь는 홀로 독립 음가가 아니라 앞 자음을 연하게 만드는 표시; ьо처럼 쓰임.
  • Щ щ는 표준어에서 대체로 /ʃt/로 분석; 러시아어 щ의 발음과 같다고 가르치면 안 됨.
  • Ю, Я는 어두 /ju/, /ja/와 자음 뒤의 연음화 기능을 구별.
  • 공식 로마자 전사는 발음 기호(IPA)가 아님. 일부 철자는 실제 음과 1:1 대응하지 않음.

기초 문법

  1. 명사의 남성·여성·중성 3성.
  2. 정관사가 명사·형용사 뒤에 붙는 후치관사(예: книга → книгата).
  3. 동사는 인칭·시제 활용을 하며 부정사는 현대 표준어에서 제한되고 да+활용형이 흔함.
  4. 격변화는 고대 슬라브어에 비해 크게 단순화되어 대명사 등에 흔적이 남아 있음.
  5. 불가리아어는 접두·접미를 활용한 상·시제 형태가 풍부함.

확인 문제

질문을 누르면 정답이 보입니다.

  1. 불가리아 표준 알파벳은 몇 자인가?

    정답: 30자

  2. Щ는 러시아어의 Щ와 같은 소리인가?

    정답: 아니요. 불가리아어 대표 발음은 /ʃt/

  3. Ъ의 대표 IPA는?

    정답: /ɤ/

  4. 어떤 문자가 독립 음소 없이 연음을 표시하는가?

    정답: Ь ь

  5. Благодаря는 어떤 뜻인가?

    정답: 감사합니다

참고 자료

IPA 표기는 학습용 대표 표기입니다. 실제 발음은 화자와 환경에 따라 다를 수 있으며, 회화 예시는 원어민 녹음이 아니라 학습을 돕는 근사치입니다.
